*Motto: Hesti Wira Sakti*

---

## 📋 Deskripsi Proyek
Website Company Profile modern, berwibawa, responsif, dan interaktif untuk **Denkesyah 04.04.04 Surakarta**. Website ini memuat informasi lengkap satuan kesehatan TNI AD, rumah sakit rujukan utama (**RS Tk. III Slamet Riyadi / RS DKT Solo**), serta **7 Klinik Pratama Kartika** yang tersebar di wilayah Solo Raya (Korem 074/Warastratama).

---

## 🚀 Cara Menjalankan Website
Website ini dibangun dengan arsitektur **Zero-Build Dependency** sehingga dapat langsung dijalankan tanpa perlu instalasi Node.js, Python, atau web server tambahan:

1. Buka folder `d:\webdkt`.
2. Klik dua kali pada file **`index.html`**.
3. Website akan langsung terbuka di peramban (Google Chrome, Microsoft Edge, Mozilla Firefox, Opera, dll).

---

## 📝 Panduan Lengkap Cara Mengedit Data & Konten Website

Website ini dirancang sangat fleksibel dengan **2 cara mudah** untuk mengedit konten:

### CARA 1: Mengedit Lewat Berkas `js/data.js` (SANGAT DIREKOMENDASIKAN ⭐)
Seluruh data teks tersimpan rapi dan modular di file:
👉 **`d:\webdkt\js\data.js`**

Anda cukup membuka file tersebut dengan **Notepad** atau text editor pilihan Anda:
1. **Mengedit Profil Pimpinan**:
   Cari bagian `komandan:` (sekitar baris 24):
   ```javascript
   komandan: {
     nama: "Letkol Ckm dr. Aris Purnomo, Sp.B", // Ubah nama komandan di sini
     pangkat: "Letnan Kolonel Ckm",             // Ubah pangkat
     jabatan: "Komandan Denkesyah 04.04.04 Surakarta",
     kutipan: "Kesehatan prima prajurit adalah penentu kemenangan dalam setiap medan pengabdian.",
     sambutan1: "Teks paragraf sambutan pertama...",
     sambutan2: "Teks paragraf sambutan kedua..."
   }
   ```
2. **Mengedit Visi Satuan**:
   Cari bagian `visi:` (sekitar baris 37):
   ```javascript
   visi: "Tuliskan visi satuan yang baru di sini...",
   ```
3. **Mengedit Misi & 3 Pilar Tugas Pokok**:
   Cari bagian `pilarTugas:` (sekitar baris 40):
   ```javascript
   pilarTugas: [
     { judul: "Dukungan Kesehatan Taktis", desc: "Penjelasan tugas pertama..." },
     { judul: "Pelayanan Kesehatan Berkualitas", desc: "Penjelasan tugas kedua..." },
     { judul: "Kemanunggalan dengan Rakyat", desc: "Penjelasan tugas ketiga..." }
   ]
   ```
4. **Mengedit Nomor Telepon, Alamat & Hotline**:
   Cari bagian kontak (sekitar baris 58):
   ```javascript
   alamat: "Jl. Slamet Riyadi No. 321...",
   teleponOperator: "(0271) 714422",
   hotlineIGD: "(0271) 713311",
   whatsappSiaga: "0812-2600-4404"
   ```
5. **Mengedit / Menambah Faskes & Jadwal Dokter**:
   Cari bagian `faskes:` atau `jadwalDokter:`. Anda bisa mengubah nama klinik, dokter yang bertugas, jam praktik, dan nomor telepon.

*Setelah mengubah dan menyimpan `data.js`, cukup buka kembali `index.html` atau tekan tombol **Refresh (F5)** di browser untuk melihat hasilnya seketika!*

---

### CARA 2: Mengedit Langsung di Berkas `index.html`
Jika Anda ingin mengubah tata letak, menambahkan kalimat statis baru, atau mengubah judul bagian:
1. Buka berkas **`d:\webdkt\index.html`** dengan Notepad atau VS Code.
2. Cari teks yang ingin diubah (Gunakan tombol `Ctrl + F`):
   - **Nama Pimpinan**: cari id `pimpinan-nama` (baris ~316)
   - **Kutipan Pimpinan**: cari id `pimpinan-kutipan` (baris ~325)
   - **Sambutan**: cari id `pimpinan-sambutan-1` (baris ~340)
   - **Visi**: cari id `profil-visi` (baris ~354)
   - **Motto**: cari id `profil-motto-desc` (baris ~363)
3. Simpan file (`Ctrl + S`), lalu muat ulang halaman di browser.

### 🖼️ Cara Mengganti Foto Komandan / Pimpinan Satuan
1. Siapkan file foto pimpinan dengan rasio potret (format `.jpg` atau `.png`).
2. Masukkan file foto tersebut ke dalam folder `d:\webdkt` (misal dinamakan `komandan.jpg`).
3. Buka `d:\webdkt\index.html` sekitar baris 299 pada bagian `<!-- Graphic Avatar TNI Ckm -->`, Anda dapat mengganti SVG ilustrasi dengan tag `<img>`:
   ```html
   <img src="komandan.jpg" alt="Foto Komandan" class="w-full h-full object-cover rounded-2xl">
   ```
